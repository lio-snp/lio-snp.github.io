0. 两条看似矛盾的曲线

我用同一批权重、同一批文本，算了两个数：

  • 最后一层表征与 step 0（完全没训练过的随机初始化）的余弦相似度：末期是 −0.003，也就是几乎正交。
  • 最后一层表征与它上一个快照的余弦相似度：中位数 +0.993，整个训练过程里只有一次低于 0.9。

同一批数据，一个说"面目全非"，一个说"几乎没动"。两个数都对。 这篇文章想说的是："模型漂移了多远""模型停了没有"这类问题，答案取决于你拿谁当参照、用哪个指标——我最初没有把这两个选择区分清楚。

TL;DR

  1. 我一开始想用一条曲线回答"模型停了没有"，结果发现自己换了两次变量。
  2. 我以为末期的残余变化"只是学习率还没衰减到零"——查下去发现，漂移速度与学习率有相关性，但 116k 附近还有一次约 22 倍的跳变值得单独检查（见第 4.3 节）。
  3. 检查过程中发现了指标实现和快照标注的问题。第 7 节记录了这段排查过程。

1. 背景：两条启发线索

关于大模型的内部表征，有两类常被并列引用的观察：

  • 机制侧：训练过程中会浮现出可解释的结构，比如"归纳头"（induction head）——专门做"复制前文模式"的注意力回路，它的出现与上下文学习能力的变化在时间上相关。
  • 评估侧：一个能力"突然出现"，可能只是打分方式造成的。同一个能力换成连续指标，曲线就平滑了——所谓涌现，可能部分是度量的假象。

这两条线索关注的问题并不相同（一个讲机制与能力，一个讲跨规模评估的度量效应），我把它们放在一起，只是因为它们都指向同一个测量问题：训练动力学里，"看起来突变"和"其实连续"之间的界线，很依赖你怎么测。

这两类工作让我想到一个更具体的问题：如果沿着 Pythia 的 154 个 checkpoint 观察，表征变化更像是连续的漂移，还是偶尔发生的跳变？

先把四个词说清楚

  • 快照 / checkpoint：训练过程中每隔一段存下来的模型副本。Pythia 官方公开了 154 个，从第 0 步（随机初始化）到第 143000 步。Hugging Face 上它们叫 revision，本文统一叫快照。
  • 激活值 / activation：某个神经元看到某段文字时"兴奋"的程度。它就是一个数字。
  • 隐状态 / hidden state：模型读完整句话后，内部留下的一串 2048 个数。人类读不懂，所以要想办法把它变成一个点画在平面上。
  • 正交：两个向量夹角 90°，余弦相似度为 0。关键的反直觉点：在 2048 维空间里，两个随机向量的余弦相似度本来就接近 0。所以后文看到"余弦 ≈ 0"，不要读成"天翻地覆"，它更准确的意思是"没有特别对齐"。

2. Setup

对象是 Pythia-1B——选它是因为它把同一套配方、同一批数据的 154 个中间快照全部公开了。

我写了一个 126 条文本的探测集：9 个语义族（标点、数字/日期、语法、数学、代码、少样本 ICL、人名、情感、定义）× 中英双语 × 每格 7 条。之所以要这么"杂"，是因为我想看的不是"模型懂不懂语法"，而是同一个神经元在不同阶段被什么点燃——那需要探测集里同时存在标点、代码、数学式。

每个快照上做一次前向，记录 5 个采样层（第 0/4/8/12/15 层）的平均池化与末位 token 隐状态、每个 MLP 神经元的峰值激活及触发它的 token、以及这批文本的 loss。

这次用双卡处理了 154 个 checkpoint，耗时约 4.7 小时。每个 checkpoint 的流程是：下载对应 revision 的权重（4 GB）、做前向计算、保存派生统计，再删除临时权重文件。

3. Loss 与表征变化

先看右下角：这 126 条文本上的 loss 从 10.98 → 3.40。10.98 是什么概念？Pythia 的词表有 50304 个词，瞎猜的 loss 就是 10.83。也就是说模型从"完全随机"走到了真的在预测。

但它并不是一条平滑的直线：153 个相邻区间里有 56 次 loss 上升，最大的一次上升出现在 step 90000（+0.55）。总体趋势明确，细节一点也不"干净"。

再看左上角：同一时期，最后一层表征与 step 0 的余弦从 1.00 掉到 −0.003，接近 0，也就是方向接近正交。

Takeaway：在这批文本上，loss 总体下降，表征与初始化的方向也逐渐偏离。仅凭 loss 曲线，还不能判断表征是否停止变化。

4. 三个指标，三个问题

我一开始想用一条曲线回答"停了没有"。后来发现，与初始化的距离、相邻快照的位移、样本关系结构，回答的是三个不同的问题。

4.1 与初始化的距离：回答"离随机有多远"

看左下角的逐层剖面：所有层都从 1.0 出发，在最初几十步内急速坠落。

这里有个细节值得慢一点看（第 15 层）：

变化最剧烈的是 8→16 这一步（0.906 → 0.300），不是第 8 步。而这个区间正好是 warmup ——Pythia 的学习率在 1430 步内从 0 线性升到峰值 2.5e-4。这提醒我，解读早期的变化速度时，也需要考虑学习率正在上升。

一个容易混淆的地方：我第一版把这个量写成"82.8% 的漂移在 step 100 完成"，两处都错：正确的快照是 step 128（我的脚本取了最近的快照却打印了目标值，这是个 bug）；更要紧的是这个量根本不单调——step 32 累积 87.9%，step 64 反而降到 82.3%。因为它并不单调，把它叫作"完成度"容易产生误解。

Takeaway：与随机初始化的距离回答的是"离随机有多远"，不能拿来回答"最近累积了多少变化"。

4.2 相邻快照的位移：回答"这一步迈了多大"

换成相邻快照之间的位移（除以步数，因为后期快照间隔更大）。第 15 层：

为什么"与上一步的余弦"和"与 step 0 的余弦"能差这么多？因为前者的参照点跟着你一起走：

4.3 学习率趋势与一次跳变

我接着检查了另一种可能：末期的微小位移，也可能只是学习率还没衰减到零。Pythia 超参公开：峰值 2.5e-4，cosine 衰减到 2.5e-5，warmup 1430 步。我把它算了出来。

量结果
学习率全程降 10 倍（2.5e-4 → 2.5e-5）
漂移速度全程降 ~2.5 个数量级
warmup 后 log(速度) vs log(学习率) 斜率0.71 – 0.89
该拟合的 R²0.58 – 0.76

这个拟合的 R² 为 0.58–0.76。在所用拟合区间内，log(速度) 与 log(学习率) 存在相关性，但它不能单独说明学习率是变化的原因，也没有覆盖全部波动。

因此，我暂时不把末期的非零位移直接解释为独立于学习率的变化。继续看残差时，我注意到了 116k 附近的一个异常区间：

在 step 115k → 116k，第 15 层的每步位移从 0.0783 跳到 1.7007——22 倍，而那一带的学习率在平滑下降。连续两段（115k→116k、116k→117k）都是这个量级，尾部（≥133k）的中位数是 0.0756，事件是它的 11.8 倍。

我做了几项一致性检查：Hugging Face 上 step114000–118000 五个权重文件的 sha256 互不相同。这说明文件内容不同，但还不足以排除加载流程或数值精度的影响。表征侧还观察到了这些现象：

  • 方向是全局相干的：126 条探测文本的位移几乎同向，中层 cos(各自位移, 平均位移) = +0.99；而普通区间（133k→134k）只有 0.58。
  • 相邻快照余弦从 0.998 → 0.184 再弹回（上图 (c)），末位 token 表征同步（0.997 → 0.339），逐层都发生。
  • 去掉各自均值、再投影掉共同方向之后，余弦仍只有 0.6 左右——变化仍然存在，但仅凭这个结果还不能把它定性为旋转。

在当前探测集上，平均 loss 的变化较小（+0.013 nats）；分组结果有升有降（code −0.053、names +0.117）。这还不能说明模型的其他行为没有受到影响。

目前，我把观察分成两部分：

  1. 漂移速度与学习率存在相关性——上述拟合的 R² 为 0.58–0.76。
  2. 116k 附近出现了约 22 倍的表征位移跳变——在这批探测文本上，位移方向较一致，平均 loss 未伴随同等明显的变化。其成因还不清楚。

我原来把这个区间当成了学习率变化下的普通波动。现在更合适的做法是把它单独列出来，继续检查。

5. CKA 和余弦测的不是一回事

换成 CKA（Centered Kernel Alignment）——衡量"两组表征的样本间相似结构是否一致"的指标，常用于表征相似性分析。看左上角的 154×154 热力图：

  • step 0 与所有已训练模型之间是暗的——初始化确实是个异类。
  • 后期快照彼此几乎全亮（CKA ≈ 1）：在当前探测集和 CKA 指标下，后期快照的样本关系结构较接近。
  • 中间层（第 8 层）与 step 0 的 CKA 从 1.0 一路衰减到 0.134；最后一层到 0.321。

和余弦放在一起，出现一个需要小心处理的组合：最终层与 step 0 的余弦 ≈ 0（正交），但 CKA 还有 0.32。

容易犯的错是直接说"这只是一次旋转，样本关系被保留了"。这个推论不成立：如果两个表征之间只差一个正交变换，线性 CKA 应该恰好是 1，不是 0.32。所以 0.32 说明的是别的东西：既不是无关，也不是同一套结构。

我加了一个打乱对照来帮助理解这个数值——把样本对应关系打乱（保持表征不变，只打乱"哪一行是哪条文本"）：

值
真实 CKA(step 0, 最终)0.321
打乱 100 次0.095 ± 0.009（最大 0.118）

真实值远高于打乱分布，说明确实存在超出偶然的样本对应结构；但它既不能读成"保留了 32% 的结构"，也不能读成"相似度排序不变"。

Takeaway：这两个指标的数值不能直接互换解释。 余弦说"方向不再对齐"，CKA 说"样本之间的对应还没散掉"，两句话可以同时成立。

6. 漂移长什么样：从神经元到语义

上面全是整体指标。往下钻一个尺度：单个 MLP 神经元。做法是经典的 max-activating exemplars——对每个神经元，找出让它激活最高的文本片段。我自动挑出 4 个"改了行"的神经元：

7. Debugging notes

分析过程中，我发现并修正了三个 bug；第三个是在后续核对中发现的。

坑 1：CKA 输入维度搞错。 我的 CKA 函数期望 [快照, 样本, 特征]，而我把 5 个采样层放在了最后一维——等于告诉它"每个样本有 5 个特征"。整张热力图都是错的。

坑 2：CKA 归一化写错。 我把 Frobenius 内积 sum(G_i ∘ G_j) 写成了矩阵乘。发现它的线索是：CKA 矩阵的对角线应该恒等于 1，而我的算出来不是。 修好坑 2 之后，才意识到矩阵里那些"神秘的暗带"来自坑 1。

坑 3：最近邻快照打印错。 我的汇总脚本用 argmin|step - 100| 取快照，实际取到的是 step 128，却把 "100" 打印了出来。于是"82.8% 的漂移在 step 100 完成"这句话，从数字到含义都是错的。

这几个 bug 让我更留意两个细节：相似度矩阵的对角线是否符合预期，以及脚本显示的快照编号是否真的是实际取到的那个。图能画出来，并不代表我已经把它算对、读对了。

8. Limitations

  • 探测集是 126 条手工文本，不是百万 token 级语料。这里的观察都受这批文本的覆盖范围限制，尚不能直接外推到更广泛的语料。
  • 只采样了 5 / 16 层。
  • max-activating exemplars 用的是模型崩溃前的文本碎片，不是大规模语料扫描。
  • Pythia 的学习率从未降到 0，所以"表征最终是否收敛"这个问题，用这批快照无法回答。（注意：把学习率设成 0 则权重必然停止更新，所以这不是一个"设成 0 就能验证"的实验，而是在问：除了学习率设定的速率之外，表征还有没有自己的动力学。 116k 附近的事件值得进一步检查，但目前还不能据此确定答案。）
  • 116k 事件的成因我不知道。它是不是 Pythia 训练数据顺序的某个边界、是不是与精度/优化器状态有关，我还没有结合训练配置和完整权重弄清楚——目前观察到了相干的表征变化，但成因及其行为影响仍不清楚。

9. What’s next

我还想弄清第 4.3 节的那个区间：为什么表征位移出现了约 22 倍的跳变，而当前探测集上的平均 loss 变化较小？

一个方向是在 Pythia 的其他规模（70M 到 12B）上重复检查，看看是否也有类似事件，以及出现频率是否随规模变化。这可以帮助判断当前观察是否只出现在这一个模型上。

另一件我想尝试的事是把探测集换成 Pile 里几十万 token——现在所有"持续漂移"的判断都建立在我自己写的 126 条文本上。

接下来，我想先做这两个检查。

附：Takeaways

这次实验让我更留意：参照点、指标和层都会影响我对"漂移了多少"的理解。 下面是我留下的几点体会：

  1. 我会把这两条曲线放在一起看：与初始化的距离（回答"离随机有多远"）+ 相邻快照的位移（回答"这一步迈了多大"）。用前者回答后者，会既夸大早期、又掩盖后期，而且它甚至不单调。
  2. 我之前不小心换了两个变量；保持指标一致之后，参照系的区别才更容易看清。
  3. 对照 loss 和表征指标时，116k 附近的观察说明，它们未必同步变化。
  4. 我也开始留意"残余变化"与学习率趋势的关系。这次，继续检查残差让我注意到了 116k 附近的事件。
