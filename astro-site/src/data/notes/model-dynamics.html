0. 两个参照点

同一批模型快照与文本，在两个参照点下得到不同的表征变化结果：

  • 最后一层表征与 step 0（随机初始化）的余弦相似度，末期为 −0.003，方向几乎正交。
  • 最后一层表征与前一个快照的余弦相似度，中位数为 +0.993，整个训练过程中只有一次低于 0.9。

前者衡量与固定起点的方向对齐，后者衡量局部区间内的方向对齐。表征可以经过许多次小幅变化，逐渐偏离初始化。因此，解读曲线需要同时明确参照点与指标。

TL;DR

  1. 我一开始想用一条曲线回答"模型停了没有"，结果发现自己换了两次变量。
  2. 我以为末期的残余变化"只是学习率还没衰减到零"——查下去发现，漂移速度与学习率有相关性，但 116k 附近还有一次约 22 倍的跳变值得单独检查（见第 4.3 节）。
  3. 检查过程中发现了指标实现和快照标注的问题。第 7 节记录了这段排查过程。

1. 背景与问题

两类研究为观察表征变化提供了不同的出发点：

  • 机制侧：训练过程中可以形成可解释的回路。例如，归纳头（induction head）帮助模型复制前文模式，其形成与上下文学习能力的变化在时间上相关。
  • 评估侧：能力曲线是否显得突然，可能取决于打分规则。在一些跨模型规模的评估中，连续指标呈现的变化比离散得分更平滑。

两者研究的对象不同：一个关注训练中的机制形成，一个关注跨规模评估中的度量效应。它们都涉及可观测量的选择。这里的问题更具体：沿着 Pythia 的 154 个快照观察，表征变化是持续漂移，还是存在变化幅度异常大的区间？

术语

  • 快照 / checkpoint：在某个训练步保存的模型副本。Pythia 公开了 154 个快照，从第 0 步（随机初始化）到第 143000 步，在 Hugging Face 上以 revision 提供。
  • 激活值 / activation：神经元对输入的数值响应。
  • 隐状态 / hidden state：模型内部的表征向量，在这个模型中包含 2048 个坐标。投影可以将其中部分变化显示在二维平面上。
  • 正交：两个向量夹角为 90°，余弦相似度为 0。在 2048 维空间里，独立、各向同性的随机方向本来就倾向于具有接近 0 的余弦相似度。 接近零表示方向缺少对齐，具体含义取决于比较对象。

2. Setup

分析对象为 Pythia-1B，使用同一次训练、相同配方与数据下公开的 154 个中间快照。

探测集包含 126 条手工文本：9 个类别（标点、数字/日期、语法、数学、代码、少样本 ICL、人名、情感、定义）× 中英双语 × 每组 7 条。混合输入类型，便于比较同一神经元在不同训练阶段对哪些输入产生响应。

每个快照做一次前向计算，记录 5 个采样层（第 0/4/8/12/15 层）的平均池化与末位 token 隐状态、每个 MLP 神经元的峰值激活及触发它的 token，以及探测文本的 loss。

双卡处理耗时约 4.7 小时。每个 revision 的权重（4 GB）下载后用于前向计算，保存派生统计后删除临时权重文件。

3. Loss 与表征变化

右下角显示，这 126 条文本上的 loss 从 10.98 → 3.40。Pythia 的词表包含 50304 个 token，均匀预测的 loss 为 10.83，可以作为初始值的参照。

下降并不单调：153 个相邻区间中有 56 次 loss 上升，最大增幅位于 step 90000（+0.55）。同一训练过程中，最后一层表征与 step 0 的余弦从 1.00 降至 −0.003（左上角）。

Loss 衡量探测文本上的预测表现，余弦衡量表征方向的对齐。两者的总体趋势尚不能说明训练后期的表征是否停止变化；这需要进一步比较后期快照。

4. 参照点、区间与学习率

与初始化的距离、局部位移、样本间关系，描述表征的三个方面。本节先看前两种比较，第 5 节再用 CKA 检查样本关系。

4.1 与初始化的方向对齐

逐层剖面从 1.0 出发，在最初几十步内快速下降。第 15 层的部分数值为：

这些观测中，变化最大的是 step 8 → 16（0.906 → 0.300）。它位于 warmup 区间：Pythia 的学习率在 1430 步内从 0 线性升至 2.5e-4。因此，早期的变化发生在学习率上升的过程中。

第一版曾把由此得到的量描述为“82.8% 的漂移在 step 100 完成”。实际选取的是 step 128（见第 7 节）。更根本的问题是，这个量不单调：step 32 为 87.9%，step 64 降至 82.3%。它不能解释为已经完成的变化比例。

4.3 学习率趋势与 116k 附近的事件

位移缩小可能部分来自更新尺度的缩小。根据公开配置重建的 Pythia 学习率曲线，峰值为 2.5e-4，经 cosine 衰减至 2.5e-5，warmup 为 1430 步。

在所用拟合区间内，log(速度) 与 log(学习率) 存在相关性，R² = 0.58–0.76。这不能单独确立学习率与趋势的因果关系，也不能解释全部波动。116k 附近的区间就偏离了平滑的学习率变化：

step 115k → 116k，第 15 层的每步位移从 0.0783 升至 1.7007，约 22 倍。 连续两段（115k→116k、116k→117k）都处于这个量级，而学习率在平滑下降。尾部（≥133k）的中位数为 0.0756，事件是它的 11.8 倍。

Hugging Face 上 step114000–118000 五个权重文件的 sha256 互不相同，说明文件内容不同，但这一项检查不足以排除加载流程或数值精度的影响。表征测量还显示：

  • 位移方向具有一致性：126 条探测文本的位移几乎同向，中层 cos(各自位移, 平均位移) = +0.99，普通区间 133k→134k 则为 0.58。
  • 相邻快照余弦从 0.998 → 0.184 后回升（图 (c)）。末位 token 的相似度也发生变化（0.997 → 0.339），各采样层都有变化。
  • 去掉各自均值、再投影掉共同方向后，余弦仍约为 0.6。差异仍然存在，但这不足以将变化解释为旋转。

当前探测集的平均 loss 变化为 +0.013 nats，不同类别有升有降（code −0.053、names +0.117）。因此，这次事件在表征位移上比在这些文本的平均 loss 上更明显。其成因及对其他行为的影响仍未确定。

5. CKA 下的样本关系

余弦比较向量方向；CKA（Centered Kernel Alignment）比较两组表征的样本间相似结构。它关注的是：在一个快照中表征相近的文本，在另一个快照中是否仍有相应关系。154×154 热力图显示：

  • step 0 与训练后快照之间的颜色较暗，说明在这个指标下，它们的样本相似结构有所不同。
  • 后期快照之间大多较亮（CKA ≈ 1），在当前探测集上具有较接近的样本关系。
  • 与 step 0 相比，第 8 层的 CKA 从 1.0 降至 0.134，最后一层为 0.321。

最终层与 step 0 的余弦约为 0，CKA 约为 0.32。这不能用纯旋转解释：正交变换下的线性 CKA 为 1。解释中间值，还需要一个参照基线。

打乱对照保持表征不变，只破坏行与文本之间的对应关系：

对照值
真实 CKA(step 0, 最终)0.321
打乱 100 次0.095 ± 0.009（最大 0.118）

真实值高于打乱分布，支持存在超出这一基线的样本对应结构。它不能解释为“保留了 32% 的结构”，也不能说明相似度排序不变。方向对齐与样本关系描述的是表征的不同方面。

7. 实现修正

分析早期版本中有三项实现错误。以上测量结果使用修正后的实现。

CKA 输入维度。 函数期望 [快照, 样本, 特征]，实际把 5 个采样层放在了最后一维，相当于每个样本仅有 5 个特征，导致热力图计算错误。

CKA 归一化。 Frobenius 内积 sum(G_i ∘ G_j) 被写成矩阵乘，导致自相似性不为 1。修正归一化后，输入维度错误造成的暗带才进一步显现。

快照标注。 汇总脚本通过 argmin|step - 100| 选取 step 128，却打印了“100”。早期“82.8% 在 step 100 完成”的表述，同时包含这一标注错误与第 4.1 节所述的非单调量问题。

8. Limitations

  • 126 条手工文本不能确立结果在更广泛语料或百万 token 上的适用性。
  • 只采样了 5 / 16 层。
  • Max-activating exemplars 来自模型崩溃前保留的文本碎片，并非大规模语料扫描。
  • 有限快照不能确立最终收敛。Pythia 的学习率仍非零；设为 0 会按定义停止权重更新。要区分学习率趋势与其他变化来源，需要另设干预实验。
  • 116k 事件的成因未确定。 数据顺序边界、精度与优化器状态，仍需结合训练配置和完整权重检查。当前 loss 测量也不足以刻画它对其他行为的影响。

9. 后续问题

主要的未解观察是：116k 附近的位移跳变约 22 倍，平均探测 loss 却变化较小。比较 Pythia 的其他规模（70M 到 12B），可以检查是否也存在类似事件，以及出现频率是否随规模变化。

使用 Pile 中几十万 token，也能比现有 126 条文本提供更广的输入覆盖。这两种扩展有助于区分探测集特有的现象与训练过程本身的变化。

测量小结

与初始化的距离描述对固定参照的偏离，相邻位移描述观测区间内的变化，CKA 描述样本关系。单独一个量都不足以确定模型是否停止变化。在当前测量中，学习率趋势伴随着整体减速，而 116k 附近仍存在一次成因未明的异常变化。
